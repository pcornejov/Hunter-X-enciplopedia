Cómo se construye

  1. 1. Ingesta

    scripts/fetch-data.mjs consulta AniList (GraphQL) y Kitsu (JSON:API) con reintentos, backoff exponencial y control del límite de peticiones. Normaliza el resultado y lo guarda como JSON en el repositorio.

  2. 2. Validación de datos

    scripts/validate-data.mjs comprueba que no falten obras ni personajes clave, que los slugs sean únicos, que las imágenes vengan de hosts esperados y que la numeración de episodios no tenga huecos.

  3. 3. Integridad referencial

    src/lib/data.ts cruza el contenido escrito en español con los datos de las APIs. Si un arco cita a un personaje inexistente, el build falla antes de generar una sola página.

  4. 4. Build y validación del sitio

    scripts/validate-build.mjs recorre dist/ y verifica enlaces internos rotos, páginas sin título o sin descripción, imágenes sin alt y ausencia de ficheros necesarios para GitHub Pages.

Contenido propio

Las APIs devuelven fichas en inglés y sin contexto narrativo. Para que esto funcione como enciclopedia en español, el sitio añade material escrito específicamente para él: los ocho arcos con sus resúmenes y equivalencias manga/anime, las seis categorías de Nen con su hexágono de afinidad, los principios del Nen, las facciones, el glosario y biografías propias del reparto principal.

Cuando una ficha muestra texto traído de AniList, se indica de forma explícita y se deja en su idioma original en lugar de traducirlo automáticamente.

Derechos

Hunter x Hunter es una obra de Yoshihiro Togashi, publicada por Shueisha y adaptada por Nippon Animation (1999) y Madhouse (2011). Este es un proyecto de fans, sin ánimo de lucro y sin relación con los titulares de los derechos.

Las imágenes no se copian a este repositorio: se enlazan directamente desde los CDN públicos de AniList y Kitsu, que son sus fuentes originales. Los textos escritos para este sitio se ofrecen para uso libre; los datos de las APIs pertenecen a sus respectivas comunidades.
